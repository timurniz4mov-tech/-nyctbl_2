# Desert Apocalypse (Апокалипсис пустыни) — Minecraft 1.20.1, Forge 47.x

Мод: рядом с игроком (в 10–100 блоках) просыпается **Сердце Пустыни** — и пустыня начинает
медленно расползаться по миру. Каждый день она растёт быстрее. Параллельно у игрока есть **жажда**.

## Что делает мод

* При появлении первого игрока в Верхнем мире на расстоянии 10–100 блоков ставится неразрушимый
  блок **Сердце Пустыни** (горит, дымит). Вокруг сразу появляется пятно пустыни.
* Пустыня растёт кругом от сердца. Скорость в день 1 — около 1.8 блока/мин, а каждый новый день
  умножается на 1.12 (настраивается). В чат приходит сообщение о новом дне и текущей скорости.
* Внутри круга: трава/земля/гравий/глина/снег -> **песок**, верхний слой камня -> **песчаник**,
  деревья, листва, цветы, трава, культуры -> исчезают, вода сверху -> песчаник,
  иногда появляются сухие кусты и кактусы. Руды и постройки игрока не трогаются.
* **Жажда** (капли над полоской голода): убывает со временем, вдвое быстрее в пустыне,
  ещё быстрее днём под солнцем и при беге, в Незере тоже быстрее.
  * Слабая жажда -> замедление, очень слабая -> слабость, 0 -> урон.
  * Утоляют: бутылка воды (+8), другие зелья (+3), молоко (+6), арбуз (+2), ягоды (+1),
    дождь, а также **присесть (Shift), стоя в воде**.
  * Творческий режим и наблюдатель жажды не имеют.
* **Компас пустыни** (ПКМ — стрелка и расстояние до Сердца). Новым игрокам выдаётся при входе
  вместе с 2 бутылками воды. Рецепт: компас в центре + 4 песка крестом.
* Сверху экрана: день апокалипсиса и расстояние до границы пустыни.

## Команды

* `/apocalypse info` — день, радиус, скорость (координаты сердца видят только операторы)
* `/apocalypse restart` — (оп) перезапустить апокалипсис рядом с вами
* `/apocalypse setradius <число>` — (оп) задать радиус пустыни
* `/apocalypse setday <день>` — (оп) перемотать апокалипсис на нужный день

## Настройки

Файл `config/desertapocalypse-common.toml` (появляется после первого запуска): дистанция появления,
стартовый радиус, базовая скорость, ускорение в день, максимальная скорость, нагрузка на сервер
(samplesPerTick), отключение жажды, длительность полной жажды, стартовый набор.

## Как получить .jar через GitHub

1. Распакуйте ZIP.
2. На github.com создайте новый репозиторий (New repository).
3. Нажмите **Add file -> Upload files** и перетащите **содержимое** распакованной папки
   (папки `src`, `.github`, файлы `build.gradle`, `settings.gradle`, `gradle.properties` и т.д.).
   Если папка `.github` не загрузилась (она скрытая), создайте файл вручную:
   **Add file -> Create new file**, имя `.github/workflows/build.yml`, вставьте туда содержимое
   файла `build.yml.txt` из архива.
4. Откройте вкладку **Actions**. Сборка запустится сама после загрузки
   (или нажмите **Build mod -> Run workflow**).
5. Когда сборка станет зелёной, откройте её и внизу в **Artifacts** скачайте
   `DesertApocalypse-jar`. Внутри будет `desertapocalypse-1.0.0.jar`.
6. Положите jar в папку `mods` (клиент и сервер), нужен Forge 1.20.1 (47.x).

Мод нужен и на сервере, и у игроков (есть сетевой пакет для интерфейса жажды).
